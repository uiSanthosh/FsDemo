# BestBank Program Console

Single-page fintech dashboard (HTML, CSS and vanilla JS, no build step) with light and dark themes.

## Run
Open `index.html` in a browser. Fonts (Inter, Outfit, JetBrains Mono) load from Google Fonts.

## What is in it
- FSS sidebar (text-only menu, expandable Setup, red and black brand accent)
- Summary widgets that read live state
- Card actions, 50+ program configuration toggles
- Intelligent HSM rerouting diagram
- Configurable daily transaction limit ruler with limit rules
- Auto Fetch CBS with master toggle and selectable fields
- Light/dark toggle (follows system setting, choice remembered)
